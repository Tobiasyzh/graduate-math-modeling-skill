# 图与网络

先定义节点、边、方向、权重单位、时变性和容量。地理距离、运输时间、成本、概率不是可随意互换的边权。断连、重复边、自环和有向/无向转换要检查。

| 结构 | 起点 | 升级条件与检查 |
|---|---|---|
| 单起终点最短路 | 非负权Dijkstra | 负权需其他算法并检查负环；到达时间依赖出发时刻时用时变模型 |
| 全网低成本连接 | 最小生成树 | 不解决多车巡回或时窗服务问题 |
| 容量与供需 | 最大流/最小费用流 | 检验流守恒、容量、供需平衡与不可达需求 |
| 车辆路径/调度 | 最近邻等可行构造基线 | 加容量/时窗/多仓约束后用MILP、CP或局部搜索 |
| 网络可靠性 | 连通与失效模拟 | 节点相关失效、级联效应须有模型依据 |

可视化只说明结构，不证明最优。输出节点ID映射、路线/分配表、独立重算的总成本与约束校验。网络中心性是结构指标，不自动等于现实影响力或因果作用。

使用启发式时保存最好可行方案与运行预算；后续局部搜索不能丢掉可行性。把复杂网络压缩或分区后，检查聚合是否改变关键瓶颈。
