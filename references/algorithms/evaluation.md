# 综合评价、聚类与指标

先判断题目是否真的要求价值判断。若有真实标签可评价预测，则不要随意把预测任务改成熵权评分。没有外部标准时，综合评分是偏好下的排序，不是客观真理。

1. 写清评价对象、使用者、指标方向与单位，区分效益型、成本型、区间/目标型指标。避免两个高度相关的指标重复计权。
2. 给透明的等权/单指标基线。标准化方法及目标值须有理由；常数列先移除或单列处理，不除以零。
3. AHP适合可解释的专家偏好；提供判断依据、相容性/一致性检查。熵权反映样本差异性，不等于社会重要性。计算中约定 `0 log 0=0`，但输入概率要非负且归一化；全列无差异时单独处理。
4. TOPSIS先解释距离、标准化和权重。缺失指标与新增对象可能改变排名，不能只给最终分数。
5. 检查权重扰动、标准化替代、删去单指标/单对象时排名是否稳定；有外部实际表现时做独立比对。区分稳定头部与名次不确定的对象。

聚类不是天然类别真值：解释距离与特征尺度；比较合理的簇数和噪声处理，查看轮廓系数等内部指标，也看重采样稳定性和业务解释。t-SNE/UMAP图的视觉分离不能单独证明高维簇真实存在；聚类后用于预测时避免全数据拟合引入泄漏。

交付至少含指标定义表、可复算公式/代码、权重来源、稳定性结果及适用边界。别把0.73分解释成73%的成功概率。
