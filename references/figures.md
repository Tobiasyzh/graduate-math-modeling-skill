# 用图表支撑论证

每图先写一句要支持的结论，再指定数据路径、运行ID、变量单位、比较条件、误差/区间含义与拟放位置。没有结论用途就删图，不凑固定数量。概念示意图标“示意”，不能生成看似真实的实验曲线。

| 要回答的问题 | 适合的形式 | 必备信息 |
|---|---|---|
| 相对基线有多少差异 | 表格/点区间图/少量分组柱图 | 同一切分、指标方向、预算、区间定义 |
| 预测是否偏 | 真实值-预测散点、残差图 | 同单位、参考线、留出数据标识 |
| 随时间是否有效 | 时间曲线+预测区间 | 切分时刻、步长、真实未来范围 |
| 约束是否满足/资源怎样分配 | 甘特图、分配表、约束裕量 | 容量、时间窗、单位、可行性 |
| 参数影响与代价 | 敏感性曲线、Pareto点图 | 参数范围依据、目标单位、真实可行方案 |
| 机理与模拟一致吗 | 理论-仿真曲线、误差图 | 条件一致、重复次数、差值定义 |
| 空间或图像预测 | 同一色标的多面板图 | 物理量、色标、时空位置、代表样例选择 |

## 制图标准

图和表从同一结果文件生成，避免手工改数。保留原始数据和脚本；表格采用有意义的精度和单位。用适度字号、白底、有限配色、线型/标记冗余编码；不依赖红绿区分。多面板比较统一坐标或明确说明差异。

柱图一般从零开始；其他图缩放应标清，不以截断轴放大改善。误差棒注明SD/SE/CI、样本单位和n；这些概念不互换。没有重复实验/概率依据，不添加装饰性置信区间。

曲线/文字优先导出矢量PDF/SVG，另存300dpi或按官方要求的PNG。栅格热图/图像保留恰当分辨率。数值图用matplotlib等绘图库，不用生成式AI伪造数据面板。

实际打开导出的图，再在最终文档中按阅读尺寸检查：缺字、轴单位、图例、色标、标注是否碰撞/截断，图注能否独立理解，正文是否引用正确图号。只看到文件存在不能写“视觉检查通过”。

## 内置轻量绘图助手

`scripts/plot_results.py`读取CSV生成线图/散点/柱图及来源指纹，导出SVG+PNG。它只是常见数值图的起点，不替代针对题目的多面板设计。

```text
python <skill-dir>/scripts/plot_results.py --input results/compare.csv --out figures/comparison --kind bar --x model --y mae --xlabel Model --ylabel "MAE (m)"
```

可加`--group`生成多系列，`--error`指定非负对称误差列，并用`--error-label`说明含义。不提供误差列就不画误差棒。输出前缀必须未被占用；改图使用新版本。

若需要Word、LaTeX、其他格式，优先复用本地可用的专业工具/技能，保留可编辑表格与公式。无需为了“高级感”强制Nature版式，赛事模板优先。
