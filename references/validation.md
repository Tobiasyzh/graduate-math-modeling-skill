# 验证与高价值改进

## 区分四个问题

1. 实现是否对应所写公式？用小例、约束重算和独立实现检查。
2. 数值方法是否解得足够准确？看残差、gap、收敛/网格、精度和停止条件。
3. 模型是否解释/预测目标现象？看留出数据、独立观测、合理基准及适用范围。
4. 给定这些不确定性，建议是否仍然可行、有用？看参数、场景和代价敏感性。

四者不可替代。理论与模拟共享假设时一致并不证明现实有效；拟合好不代表外推好；找到了可行解不代表最优。

## 最小而有效的验证包

| 模型 | 优先证据 | 避免的伪证据 |
|---|---|---|
| 优化 | 独立目标/约束复算、小例精确解、上下界、预算可比 | 只画迭代下降曲线即称全局最优 |
| 预测 | 正确独立单位的留出/交叉验证、朴素基线、误差分布 | 训练精度、挑选最好随机种子 |
| 机理 | 量纲/守恒/极限、参数可识别、数值收敛、校准外验证 | 理论公式复算自己作为全部验证 |
| 评价 | 权重/归一化/删指标稳定性、外部参照 | 排序数字漂亮就称客观准确 |
| 仿真 | 重复试验区间、暖机与事件逻辑、小例对照 | 单次轨迹证明普遍结论 |

## 怎样建立可信改进

先定义现有失败模式，再提出改变它的机制，最后设计能区分解释的实验。预算有限时一项可信消融比十项没有对照的新方法更有价值。

- 所有模型共用数据版本、切分/场景与评价口径；代价不同则一起报告。
- 消融一次改变一个关键模块，或用因子设计识别交互。多项同时改变的收益不能全归某一项。
- 敏感性区间来自测量误差、文献或明确假设，解释为何选择；不能只选不会改变结果的小扰动。
- 在小样本/相关数据中重采样用正确单位，不能把大量相邻帧当大量独立证据。
- 看失败场景和可用范围，而不只展示最成功的例子。模型越复杂越需要解释增加的自由度由什么数据支撑。

所有“提高”重算方向和百分比分母，记录原始值与显示值。摘要、图上标注、结果表共用同一文件生成。变化在估计波动范围内时写“未观察到稳定优势”，不要写“显著提升”。

## 如何排序返工

先修题意误读、数据泄漏、不可行解、错误公式、指标算错；再补会改变方案选择的验证；最后完善图注、版式与措辞。审查结论分为致命错误、缺证据、可选改进，给文件/公式/数据定位、实际影响及复验办法。没有新证据不要无限轮次“润色”。
