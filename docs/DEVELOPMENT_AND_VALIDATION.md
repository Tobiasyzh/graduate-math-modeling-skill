# 开发与验证说明

版本：1.0.1  
状态日期：2026-09-01

本文说明技能已经验证的部分、研究证据和仍需人工判断的边界。它不是比赛获奖效果报告。

## 已完成的研究与实现

- 核验华为杯 2026 邀请函、华为杯 2025 历史 AI/格式/提交文件，以及 MathorCup 2026 章程、AI 与格式文件。当前规则、历史规则和未知字段分开记录。
- 阅读三套公开数学建模技能的入口和关键实现，只提取设计思想，没有执行外部脚本或复制第三方源码。
- 精读七篇具有队号、奖项和全文证据链的公开作品，并加入一篇证据等级较弱的补充样本。原始 PDF 不进入仓库或分发包。
- 完成按阶段加载的技能入口、方法与流程参考、六类算法卡、论文大纲、合成数据与求解程序。
- 实现六个命令行工具：项目初始化、实验记录、项目审计、提交冻结、结果绘图和完整演示。

## 工具测试

运行：

```text
python tests/test_tools.py
```

最近一次结果为 Python 3.12.7 下 14/14 通过。测试覆盖：

1. 初始化不会覆盖已有项目；
2. 实际子进程、标准输出、Windows 路径归一化与指标绑定；
3. 输入、源码或输出变化会触发过期证据；
4. 错误数值主张不能通过审计；
5. 非零退出和缺少输出不能标为成功；
6. 旧运行 ID 和旧输出不能静默复用；
7. NaN、Infinity 和溢出浮点不能进入指标；
8. 相对路径、盘符和 UNC 路径逃逸会被拒绝；
9. 交稿阶段要求人工审核、AI 记录、来源和本届规则；
10. 冻结清单能发现精确字节变化；
11. 原子 JSON 写入失败不破坏旧文件；
12. 畸形嵌套记录会产生结构错误而不是崩溃。

这些机械检查不能证明公式正确、数据划分合理、引用真实、人工贡献充分或论文达到某个奖项水平。

## 行为评测

行为评测包含资源受限选题、错误分段收益线性化和证据冲突结果段三类模拟任务。前两类完成了启用与不启用技能的成对执行，共 13 条实质断言，两种配置均为 13/13 通过。技能版在选题任务中留下更多验证门和证据边界，但篇幅也更长。这个小样本适合回归和安全检查，不能证明技能带来性能提升。

第三类任务两种配置都在答案写出前遇到传输中断，因此被排除，没有记为失败。该评测并非盲评，也没有完整稳定的时间与 token 记录。

## 已知限制

- 通用技能不能替代赛题领域知识、原始数据检查、队员理解或本届官方规则。
- 算法卡用于选择和失败检查，不是每种算法的完整教材。
- 实验工具只追踪显式声明的依赖；运行时读取的隐式文件必须由用户登记。
- 单个随机种子不能保证 GPU 训练复现；模型代码仍需记录硬件、库和确定性设置。
- 来源指纹只能发现文件变化，不能判断变化是否影响数学结论。
- 获奖案例没有原始数据和完整代码的独立复现，也没有未获奖对照与评委打分明细。
- 工具不会自动登录、上传或提交比赛作品。

## 发布边界

分发包只包含技能入口、agent 配置、方法参考、算法卡、原创脚本、论文大纲和合成练习。原始论文、获奖表、PDF/RAR/XLSX、页面渲染、评测输出、机器路径、缓存文件和本地研究目录均被排除。逐文件哈希见 `dist/release-manifest.json`。
